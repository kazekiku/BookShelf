# 📚 BookShelf — Трекер домашней библиотеки

**BookShelf** — это мобильное приложение для читателей, которые собирают книги, комиксы, мангу и графические романы. Приложение помогает навести порядок в личной библиотеке: добавлять книги, отслеживать статус чтения и видеть свою статистику. 

Всё работает **полностью локально** — ваши данные не покидают устройство. Приложение не требует интернета, работает мгновенно и гарантирует приватность.

## ✨ Основные возможности (MVP)

- 📖 **Быстрое добавление книг:** название, автор, количество страниц и обложка (с автоматическим сжатием) — всё за 20 секунд.
- 📚 **Личная библиотека:** удобный список с обложками и цветными статусами.
- 🔄 **Управление статусами:** «Хочу прочитать», «Читаю», «Прочитано» — переключение в один тап.
- ✏️ **Редактирование:** возможность изменить название, автора, страницы или обложку уже добавленной книги.
- 📊 **Статистика:** сводка за текущий месяц (сколько добавлено и прочитано) и общая статистика библиотеки.
- 🎨 **Три темы оформления:** Светлая, Тёмная и Тёплая с эффектной анимацией «выливания» при переключении.
- 💾 **Резервное копирование:** экспорт и импорт всей библиотеки в файл JSON (защита от потери данных при смене устройства).

## 🛠 Технологический стек

- **Фронтенд:** React Native + Expo (SDK 58)
- **Навигация:** Expo Router (файловый роутинг)
- **Язык:** TypeScript
- **База данных:** SQLite (через `expo-sqlite`) + Drizzle ORM
- **Глобальное состояние:** Zustand
- **UI-кит:** React Native Paper (Material Design 3)
- **Анимации:** React Native Reanimated
- **Работа с медиа:** Expo Image Picker + Expo Image Manipulator
- **Работа с файлами:** Expo File System + Expo Sharing + Expo Document Picker

## 🚀 Установка и запуск

Для запуска проекта вам понадобятся **Node.js** и приложение **Expo Go** на телефоне (iOS / Android).

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_НИК/library-tracker.git
   cd library-tracker
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите сервер разработки:**
   ```bash
   npx expo start --clear
   ```

4. **Откройте приложение:**
   - Отсканируйте QR-код в терминале через приложение **Expo Go** на телефоне.
   - Или нажмите `a` для запуска на Android-эмуляторе / `i` для iOS-симулятора.

## 📱 Сборка APK (для Android)

Мы используем **EAS Build** от Expo для создания установочного файла, который можно передать тестировщикам.

1. Установите EAS CLI (если еще не установлен):
   ```bash
   npm install -g eas-cli
   ```

2. Авторизуйтесь в Expo:
   ```bash
   eas login
   ```

3. Запустите сборку (профиль `preview` настроен на генерацию APK):
   ```bash
   eas build -p android --profile preview
   ```

4. После завершения сборки вы получите ссылку на скачивание `.apk`.
